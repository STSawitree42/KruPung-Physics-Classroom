# SOUND QUEST: ภารกิจพิชิตโลกแห่งเสียง

เกมการเรียนรู้ฟิสิกส์เรื่อง **เสียง ม.5** แบบ Science Adventure + Physics Puzzle + Interactive Quiz
HTML / CSS / JavaScript ล้วน ไม่ต้อง build · เล่นได้ทั้งมือถือและคอมพิวเตอร์ · พร้อม Deploy บน Netlify

## ด่านทั้ง 8 ด่าน (คำถาม 102 ข้อ + ภารกิจทดลองแบบโต้ตอบ 13 ภารกิจ)
| ด่าน | หัวข้อ | คำถาม | ภารกิจทดลอง |
|---|---|---|---|
| 1 Sound Origin | การเกิดเสียง คลื่นตามยาว | 12 | ถอดรหัสคลื่นตามยาว: ระบุการสั่นของอนุภาค ทิศคลื่น และปักหมุดส่วนอัดบนภาพจำลอง |
| 2 Sound Speed | v = 331 + 0.6T, v = fλ, เสียงสะท้อน | 12 | ปรับอุณหภูมิให้พัลส์เสียงถึงเป้าตรงเวลา (ทดสอบได้ 3 ครั้ง) |
| 3 Sound Properties | สะท้อน หักเห เลี้ยวเบน แทรกสอด | 13 | นักสืบปรากฏการณ์ 4 คดี · ตามหาจุดเงียบ (ผลต่างระยะทาง = λ/2) |
| 4 Sound Intensity | I = P/4πr², β = 10 log(I/I₀) | 13 | เครื่องวัดเดซิเบลเสีย: วางไมค์ให้ได้ระดับเสียงเป้าหมาย + ทำนายที่ระยะ 2 เท่า |
| 5 Pitch and Timbre | ความถี่ ช่วงการได้ยิน ฮาร์มอนิก | 13 | จับคู่เสียงกับความถี่จากออสซิลโลสโคป · Timbre Lab สร้างรูปคลื่นจากฮาร์มอนิก |
| 6 Resonance Challenge | ท่อปลายปิด/ปลายเปิด | 13 | เลื่อนลูกสูบให้เกิดการสั่นพ้องครั้งที่ n · ปรับความถี่ท่อปลายเปิดให้ได้ฮาร์มอนิกที่กำหนด |
| 7 Beat Frequency | f_b = \|f₁ − f₂\| | 13 | เครื่องกำเนิดบีตส์ตามเป้าหมาย · ไขปริศนาส้อมเสียงไร้ป้าย |
| 8 Doppler Mission | f′ = f(v ± v_o)/(v ∓ v_s), เลขมัค | 13 | ตั้งความเร็วรถพยาบาล (ทดสอบได้ 3 ครั้ง) · วิเคราะห์กราฟความถี่ขณะรถวิ่งผ่าน |

ทุกข้อมี: โจทย์ ตัวเลือก 4 ข้อ (ปรนัย) คำตอบ คำอธิบาย ระดับความยาก หัวข้อ ระดับพฤติกรรม (ความรู้/ความเข้าใจ/การประยุกต์/การวิเคราะห์/การคำนวณ) คำใบ้ และคะแนน
คำตอบเชิงตัวเลขทั้ง 45 ข้อถูกตรวจสอบซ้ำด้วยการคำนวณอิสระ

**สำหรับครู:** เปิด `bank.html` (เช่น `https://YOUR-SITE.netlify.app/bank.html`) เพื่อดูคลังข้อสอบพร้อมเฉลย กรองตามด่าน/ประเภท/ความยาก พิมพ์ หรือดาวน์โหลดเป็น JSON (หน้านี้ไม่มีลิงก์จากตัวเกม)

## ระบบคะแนน (ตั้งค่าได้ใน `js/config.js`)
| เหตุการณ์ | XP |
|---|---|
| ตอบปรนัยถูกครั้งแรก | +100 |
| ตอบถูกหลังใช้คำใบ้ (ทุกประเภท) | +60 |
| ทำภารกิจทดลองสำเร็จ | +150 |
| แก้โจทย์คำนวณถูก | +200 |
| ผ่านด่านโดยไม่ใช้คำใบ้ (ครั้งแรก) | +100 |

- ผ่านด่านเมื่อทำถูก ≥ 60% → ปลดล็อกด่านถัดไป
- เหรียญรางวัลต่อด่าน: 🥇 ถูก ≥ 90% และไม่ใช้คำใบ้ · 🥈 ถูก ≥ 75% · 🥉 ผ่านด่าน
- เหรียญตราความสำเร็จ 8 แบบ (เช่น นักคำนวณ นักทดลอง ปรมาจารย์แห่งเสียง)

### การป้องกันการได้คะแนนโดยไม่สมควร
- ตรวจคำตอบทุกครั้งก่อนให้ XP · ไม่แสดงเฉลยจนกว่าจะส่งคำตอบ
- ปุ่มส่งถูกล็อกทันทีที่กด (กดซ้ำ/กด Enter ซ้ำไม่ได้คะแนนซ้ำ)
- XP ได้เฉพาะ “การตอบครั้งแรก” ของแต่ละข้อ เล่นซ้ำเป็นโหมดฝึกซ้อม
- คำใบ้ที่เปิดดูแล้วถูกบันทึกทันที ออกจากด่านแล้วเข้าใหม่ก็ยังนับว่าใช้คำใบ้
- ภารกิจทดลองส่งผลได้ 3 ครั้ง และนับต่อเนื่องแม้ออกจากด่าน

## เชื่อมต่อฐานข้อมูลภายหลัง
ทุกส่วนของเกมอ่าน/เขียนข้อมูลผ่าน `SQ.store` ใน `js/storage.js` เท่านั้น
1. ตั้ง `storage: 'remote'` และ `apiBaseUrl` ใน `js/config.js`
2. เกมจะ POST JSON ไปที่ API: `{action:'saveProfile', profile}` และ `{action:'logEvent', event}`
   (event มี `type` = `answer`, `level_start`, `level_end`, `profile_created`, `reset`)
3. localStorage ยังเป็นข้อมูลหลัก เกมจึงเล่นต่อได้แม้เน็ตหลุด

## เพิ่ม/แก้คำถาม
แก้ใน `js/levels/levelN.js` ทุกข้อมีฟิลด์:
`id, type ('mcq'|'num'), difficulty, bloom, topic, prompt, choices, answer, unit, tol, hint, explanation, points`
- `answer` ของปรนัย = ลำดับตัวเลือกที่ถูก (เริ่มที่ 0) ตัวเลือกจะถูกสลับตำแหน่งตอนแสดงผล
- `tol` = ค่าคลาดเคลื่อนที่ยอมรับของโจทย์คำนวณ (ค่าเริ่มต้น 2%)

## ข้อจำกัดของต้นแบบ
- คำตอบและการตรวจอยู่ในฝั่งเบราว์เซอร์ นักเรียนที่เปิด DevTools เป็นสามารถดูเฉลยได้ ถ้าต้องการใช้เก็บคะแนนจริงอย่างเข้มงวด ควรย้ายการตรวจคำตอบไปที่เซิร์ฟเวอร์ผ่านชั้น `SQ.store`
- ความคืบหน้าเก็บใน localStorage ของอุปกรณ์/เบราว์เซอร์ที่เล่น ล้างข้อมูลเบราว์เซอร์แล้วจะหาย
- ภารกิจด่าน 3, 5, 6, 7, 8 มีเสียงประกอบ (ใช้ลำโพง/หูฟังจะดีที่สุด) แต่ทุกภารกิจทำสำเร็จได้จากภาพและตัวเลขบนจอ
