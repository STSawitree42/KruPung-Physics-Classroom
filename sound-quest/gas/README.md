# เชื่อม SOUND QUEST กับระบบห้องเรียนออนไลน์ (Google Apps Script)

เมื่อติดตั้งแล้ว นักเรียนจะเข้าเกมด้วย **เลขประจำตัว (จากชีต Students เดิม) + รหัส PIN 6 หลัก**
ประวัติการเล่นบันทึกเป็นรายบุคคลใน Google Sheets ของครู เล่นต่อจากเครื่องไหนก็ได้ และนักเรียนคนอื่นเข้าดูไม่ได้

## สิ่งที่ไฟล์นี้เพิ่มให้
| ชีตใหม่ | เก็บอะไร | ใครเห็น |
|---|---|---|
| `SQ_Pins` | เลขประจำตัว ชื่อ ห้อง และรหัส PIN | ครูเท่านั้น |
| `SQ_Progress` | 1 แถวต่อนักเรียน: XP, ด่านที่ผ่าน, เหรียญทอง/เงิน/ทองแดง, % ตอบถูก, ใช้คำใบ้, เล่นล่าสุด | ครูเท่านั้น |
| `SQ_Log` | ทุกการตอบ: เวลา ด่าน ข้อ ถูก/ผิด XP ใช้คำใบ้หรือไม่ | ครูเท่านั้น |

โค้ดเดิมใน `Code.gs` **ไม่ต้องแก้** ระบบเดิมทำงานเหมือนเดิมทุกอย่าง

## ขั้นตอนติดตั้ง (ประมาณ 10 นาที)

### ขั้นที่ 1: เพิ่มไฟล์ SoundQuest.gs
1. เปิด Google Sheets ของระบบห้องเรียนออนไลน์ → เมนู **ส่วนขยาย** → **Apps Script**
2. กดเครื่องหมาย **+** ข้างคำว่า "ไฟล์" → **สคริปต์** → ตั้งชื่อ `SoundQuest`
3. ลบโค้ดตัวอย่างที่มีอยู่ แล้ววางโค้ดทั้งหมดจากไฟล์ `SoundQuest.gs` → กด 💾 บันทึก

### ขั้นที่ 2: สร้างชีตและรหัส PIN
1. ที่แถบด้านบน เลือกฟังก์ชัน **`sqSetup`** แล้วกด **▷ เรียกใช้**
2. ถ้าขึ้นหน้าขอสิทธิ์ ให้กด **ตรวจสอบสิทธิ์** → เลือกบัญชีครู → **อนุญาต**
3. กลับไปที่ Google Sheets จะมีชีตใหม่ `SQ_Pins` ซึ่งมีรหัส PIN ของนักเรียนทุกคน

### ขั้นที่ 3: อัปเดตเว็บแอป (URL เดิม)
1. ใน Apps Script กด **การทำให้ใช้งานได้** → **จัดการการทำให้ใช้งานได้**
2. กดรูปดินสอ ✏️ **แก้ไข**
3. ช่อง **เวอร์ชัน** เลือก **เวอร์ชันใหม่** → กด **ทำให้ใช้งานได้**
4. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) — เป็น URL เดิม ไม่เปลี่ยน

> ถ้าข้ามขั้นนี้ เกมจะเชื่อมต่อไม่ได้ เพราะเว็บแอปยังเป็นเวอร์ชันเก่าที่ยังไม่มี SoundQuest.gs

### ขั้นที่ 4: ใส่ URL ในเกม
1. ใน GitHub เปิดไฟล์ `sound-quest/js/config.js` → กดรูปดินสอ ✏️ แก้ไข
2. ใส่ URL ที่คัดลอกไว้ระหว่างเครื่องหมาย `' '` ในบรรทัด `apiUrl`

```js
  school: {
    apiUrl: 'https://script.google.com/macros/s/xxxxxxxxxxxx/exec'
  },
```
3. กด **Commit changes** → Netlify จะอัปเดตเว็บเกมเองภายใน 1–2 นาที

### ขั้นที่ 5: ทดลองและแจกรหัส
1. เปิดเว็บเกม จะเห็นหน้า **🔐 เข้าสู่ระบบนักเรียน** (ไม่ใช่หน้าตั้งชื่อแบบเดิม)
2. ทดลองเข้าด้วยเลขประจำตัวและ PIN ของนักเรียน 1 คนจากชีต `SQ_Pins` เล่น 2–3 ข้อ
3. เปิดชีต `SQ_Progress` จะเห็นแถวของนักเรียนคนนั้นพร้อม XP
4. แจก PIN ให้นักเรียนรายคน (เช่น พิมพ์ชีต `SQ_Pins` แล้วตัดเป็นแผ่น หรือส่งทางแชตส่วนตัว) **อย่าประกาศในกลุ่ม**

## การดูแลระหว่างภาคเรียน
| ต้องการ | ทำอย่างไร |
|---|---|
| มีนักเรียนเพิ่ม | เพิ่มในระบบห้องเรียนตามปกติ แล้วเรียกใช้ `sqGeneratePins` (สร้าง PIN ให้เฉพาะคนใหม่) |
| นักเรียนลืม PIN | ดูในชีต `SQ_Pins` |
| ตั้ง PIN ใหม่ให้นักเรียน | แก้ช่อง pin ในชีต `SQ_Pins` ได้เลย หรือเรียกใช้ `sqResetPin('เลขประจำตัว')` |
| ดูคะแนนทั้งห้อง | ชีต `SQ_Progress` (เรียง/กรองตามห้องหรือ XP ได้) |
| ดูข้อที่นักเรียนตอบผิดบ่อย | ชีต `SQ_Log` → กรองคอลัมน์ ok = FALSE แล้วนับตามคอลัมน์ task |
| ให้นักเรียนคนหนึ่งเริ่มเกมใหม่ | ลบแถวของนักเรียนคนนั้นในชีต `SQ_Progress` |

## ความปลอดภัย
- ใส่ PIN ผิด 5 ครั้ง ระบบล็อกเลขประจำตัวนั้น 10 นาที (กันการเดารหัส)
- การเข้าสู่ระบบในเกมหมดอายุใน 6 ชั่วโมง และหายเมื่อปิดแท็บ จึงปลอดภัยกับคอมพิวเตอร์ที่ใช้ร่วมกัน
- ข้อมูลที่ส่งมาจะถูกบันทึกลงแถวของนักเรียนที่ล็อกอินเท่านั้น นักเรียนเขียนทับข้อมูลของเพื่อนไม่ได้
- เกมคำนวณ XP ในเบราว์เซอร์ นักเรียนที่มีความรู้ด้านโปรแกรมมากอาจปลอมคะแนนได้ จึงควรใช้ XP เป็นคะแนนกิจกรรม/แรงจูงใจ ไม่ใช่คะแนนสอบ
- ระบบห้องเรียนออนไลน์เดิมยังเข้าด้วยเลขประจำตัวอย่างเดียว หากต้องการให้ใช้ PIN เดียวกันกับระบบเดิมด้วย สามารถพัฒนาต่อได้
